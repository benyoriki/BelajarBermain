# Pratinjau tautan & kata-kata untuk Status WhatsApp

## Yang tampil di kartu pratinjau (sudah diatur di `index.html`)
- **Gambar:** `preview-wa.jpg` (1200×630, 201 KB): tiga Dino + lencana "100% GRATIS · usia 3–8 th", pita "14 GAME EDUKASI GRATIS" dan tombol "MAIN SEKARANG".
- **Judul (42 huruf, tidak terpotong):** Buku Belajar Anak 🦕 14 Game Edukasi Gratis
- **Deskripsi (45 huruf pertama terlihat di Status):** Anak 3–8 th betah belajar! Gratis, tanpa iklan. Berhitung, huruf, logika, puzzle & cerita bareng 3 Dino 🎮

## Kata-kata untuk ditempel bersama tautan (pilih satu)
1. **Ajakan ke orang tua:** Anak bosan, bunda/ayah? 🦖 Ajak main & belajar bareng 3 Dino! 14 game seru: berhitung, huruf, puzzle, labirin dan banyak lagi. GRATIS, tanpa iklan, untuk usia 3–8 tahun 👇 https://belajarbermain.online/
2. **Singkat:** Main game yang bikin anak pintar 🧠🎮 Gratis, tanpa iklan, cocok usia 3–8 tahun. Coba sekarang 👉 https://belajarbermain.online/
3. **Untuk grup orang tua/guru:** Rekomendasi buat belajar di rumah: Buku Belajar Anak. Ada 14 permainan edukasi (hitung, huruf, logika, mewarnai, puzzle) yang gratis dan tanpa iklan. Silakan dicoba, semoga bermanfaat 🙏 https://belajarbermain.online/

## Agar pratinjau baru langsung muncul
1. Unggah `index.html` dan `preview-wa.jpg` ke hosting lebih dulu, pastikan https://belajarbermain.online/preview-wa.jpg terbuka di browser.
2. WhatsApp menyimpan pratinjau lama. Bagikan dengan tautan berakhiran `?v=2` (mis. https://belajarbermain.online/?v=2); ganti angkanya jika perlu memaksa penyegaran lagi.
3. Opsional: tempel tautan di Facebook Sharing Debugger (developers.facebook.com/tools/debug) lalu klik "Scrape Again".
4. Untuk mengubah teks pada gambar: edit `docs/make_preview_wa.py` lalu jalankan (membutuhkan Python + Pillow + font Poppins).

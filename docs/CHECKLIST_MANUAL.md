# Checklist uji manual (belum dapat dilakukan otomatis)

## HP Android (Chrome)
- [ ] Buka situs, tunggu loading 3 detik, buat profil, simpan.
- [ ] Mewarnai: ketuk area, ganti warna, Undo/Redo, Reset (gambar tetap sama), Selesai.
- [ ] Menghubungkan Garis: ketuk dua gambar; seret dengan jari; halaman TIDAK ikut bergulir saat menyeret; putar layar (garis tetap tepat).
- [ ] Labirin: usap (swipe) di labirin dan tombol panah; halaman tidak bergulir.
- [ ] Puzzle Petualangan: seret keping dengan jari; ketuk keping lalu ketuk kotak; putar layar.
- [ ] Ingat Urutan: perhatikan contoh, jawab, tekan 🔁 Ulangi contoh.
- [ ] Jawab benar/salah: dengar lagu_6 (benar), lagu_5 (salah), lagu_7 (selesai); tidak ada bunyi "beb" saat menjawab.
- [ ] Mode pesawat: muat ulang, mainkan 3 permainan, selesaikan satu, poin tersimpan.
- [ ] Instal ke layar utama; buka dari ikon; pembaruan menampilkan toast versi baru.
- [ ] Main Lagi berulang kali: poin berhenti bertambah setelah 600 poin hari itu.

## Smart TV / remote
- [ ] Panah/Enter menjelajah beranda, membuka permainan, menjawab kuis.
- [ ] Indikator fokus terlihat jelas dari jarak jauh.
- [ ] Back/Escape menutup modal; Back dari permainan kembali.
- [ ] Puzzle tanpa drag (Enter pada keping lalu kotak); Labirin dengan panah.

## Cerita (situs terpisah)
- [ ] Mulai Cerita dari situs utama, tombol 🏠 kembali ke belajarbermain.online, tombol Back browser benar.
